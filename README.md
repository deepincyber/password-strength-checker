# Password Strength Checker

A beginner-friendly Python project that evaluates the strength of a password based on common security criteria.

## Project Goal

The goal of this project is to understand the basic principles of password security while improving my Python programming and problem-solving skills.

## Planned Features

- Check password length
- Check for uppercase and lowercase letters
- Check for numbers
- Check for special characters
- Provide a password strength rating
- Display suggestions for improving weak passwords
